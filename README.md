### 🚀 Featured Projects

### 🚑 ResQLink — Ambulance Dispatch System

A full-stack ambulance availability and dispatch platform focused on improving the process of finding and requesting available ambulances.

**Key features:**

* 🚑 Nearby ambulance discovery
* 📍 Ambulance location tracking
* 🟢 Driver availability and duty management
* 🚨 Emergency request workflow
* 🔐 Role-based authentication
* 👤 Patient and driver workflows
* 📡 Driver location updates
* 🗺️ Distance calculation using geographical coordinates
* 🗄️ PostgreSQL + MongoDB
* 🧪 Jest & Supertest API testing

**Tech:** `Node.js` `Express` `React` `Vite` `PostgreSQL` `MongoDB` `Jest`
